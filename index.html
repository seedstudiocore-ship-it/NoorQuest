Setup Guide
🚀 5-Minute Setup

NoorQuest stores all data in Supabase — no localStorage at all. Follow these steps.

Step 1 — Supabase Project

Go to supabase.com → New Project. Keep your URL and anon key.

Step 2 — Run SQL Setup

In Supabase → SQL Editor, paste and run the SQL from the HTML file comments at the top.

Step 3 — Update Config

Find SUPABASE_URL and SUPABASE_KEY in the <script> and replace with yours.

Step 4 — Deploy to Vercel

Push noorquest.html to GitHub → connect Vercel → done.

Step 5 — Become Admin

After signing up, run: UPDATE profiles SET is_admin=TRUE WHERE email='you@email.com';
